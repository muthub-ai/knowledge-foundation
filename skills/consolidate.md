# Consolidate (quarterly)

1. Read the quarter's weekly lint issues.
2. Merge near-duplicate notes: keep the better path, move the other's sources and aliases into it, mark the other
   `status: deprecated` with a `supersedes` relation from the survivor. Never delete.
3. Promote drafts Muthu has approved (status stable comes from the approve workflow).
4. Refresh maps in `start-here/`. Re-run the evaluation set (`evals/questions.yaml`).
5. Write a "State of the wiki" entry in `wiki/log.md` and open one pull request.
