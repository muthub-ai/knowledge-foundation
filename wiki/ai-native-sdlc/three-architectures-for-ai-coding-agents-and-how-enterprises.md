# Overview

Platform-embedded, sandboxed and evolutionary coding agents each earn trust in a different way. Then the editor became a fleet manager. Choose and govern agents by how their work will be verified.[^s1]

# What it covers

- Platform-embedded: trust the controls you already have
- Sandboxed execution: trust the evidence
- Evolutionary search: trust the evaluator
- Then the editor became a fleet manager
- One change, three agents
- What enterprises should take from this

# Bottom line

Stop waiting, start delegating, and build the factory rather than the widget. Pick agents by how you will verify them, and own the harness that makes any of them safe.
