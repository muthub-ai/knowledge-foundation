* [The AI-native SDLC: when typing code stops being the bottleneck](the-ai-native-sdlc-when-typing-code-stops-being-the.md) - AI has made writing code cheap. * [Spec-driven development for regulated industries: audit the contract, not every line](spec-driven-development-for-regulated-industries-audit-the.md) - For complex work in regulated sectors, prompt-to-code cannot pass an audit. Making the specification the contract an AI must fulfil can, provided the spec stays anchored to the code and machines check conformance.
* [Three architectures for AI coding agents, and how enterprises should choose](three-architectures-for-ai-coding-agents-and-how-enterprises.md) - Platform-embedded, sandboxed and evolutionary coding agents each earn trust in a different way. Then the editor became a fleet manager. Choose and govern agents by how their work will be verified.
* [From pair programming to fleet management](from-pair-programming-to-fleet-management.md) - Editors now run local, background and cloud agents side by side. The leadership job shifts from writing code to designing the system that writes it.
* [Beyond vibe coding: specs as executable artifacts](beyond-vibe-coding-specs-as-executable-artifacts.md) - Ad-hoc prompting yields code that looks right but misses intent. Making the spec the gated source of truth is how AI-assisted delivery becomes repeatable.
* [Closing the loop: agents that verify their own work](closing-the-loop-agents-that-verify-their-own-work.md) - An agent that runs the tests, reads the failure and fixes its own work is the line between autonomy and a one-shot tool.

* [Code that validates itself: AI-generated assertions](code-that-validates-itself-ai-generated-assertions.md) - Only about 2.5% of open-source Java repositories use production assertions. LLMs can write them, adding the verification layer AI-written code needs.
* [Governing coding agents in a bank: a 12-point checklist](governing-coding-agents-in-a-bank-a-12-point-checklist.md) - The controls a regulated enterprise needs before coding agents write production code at scale. One page, kept current, meant to be copied into your own standards.
* [AI-Augmented Software Development Lifecycle](ai-augmented-software-development-lifecycle.md) - Coding agents brought into a large bank's software lifecycle behind one governed platform: curated context, maker/checker controls and a single gateway for every model call.
