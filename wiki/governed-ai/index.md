# Notes

* [Architecture that runs: why AI-era governance must be code](architecture-that-runs-why-ai-era-governance-must-be-code.md) - AI now writes code faster than any review board can read it, while architecture still moves at meeting speed. Governance has to become something that executes in the pipeline and in the agent's context.
* [Model is a tool, harness is the strategy](model-is-a-tool-harness-is-the-strategy.md) - Handing an AI agent a production codebase without a harness is like putting a teenager in a sports car with no dual brakes. Deterministic guardrails and sensors, owned as a platform, are what make agents safe to scale.
* [If you can't prove why an AI wrote it, you can't ship it](if-you-can-t-prove-why-an-ai-wrote-it-you-can-t-ship-it.md) - Shipping AI-generated code without recording where it came from is unmanaged risk. Regulated teams need deterministic provenance for non-deterministic models: line-level attribution, Git-native session history and AI bills of materials.
* [Adopting MCP in a bank: the four risks to solve first](adopting-mcp-in-a-bank-the-four-risks-to-solve-first.md) - The Model Context Protocol standardizes how agents connect to tools and data. It is silent on whether they should. Four risk areas a regulated institution should resolve before agents get tools.
* [Inside an Architecture-as-Code platform: a C4 walkthrough](inside-an-architecture-as-code-platform-a-c4-walkthrough.md) - The open prototype at aac.muthub.org, described in its own notation and validated by its own rules. A level-by-level C4 walkthrough of the design decisions that mattered, and what I would change before an enterprise ran it.
* [Designing an enterprise MCP registry: the control point agents need](designing-an-enterprise-mcp-registry-the-control-point.md) - As agents multiply, every enterprise needs an authoritative directory of the tools they can call. What a governed MCP registry must do, what the official registry leaves to you, and the mistakes to avoid.
* [Securing AI agents: identity, not secrets](securing-ai-agents-identity-not-secrets.md) - Agents act on their own, at machine speed, across many systems. Static credentials and perimeter thinking don't hold up. Attested identity, explicit delegation and policy enforced outside the model do.
* [MCP in three primitives: tools, resources, prompts](mcp-in-three-primitives-tools-resources-prompts.md) - MCP ended the copy-paste problem with three simple primitives. Being open is why it beat a thousand bespoke integrations.
* [Remote MCP, straight from the API](remote-mcp-straight-from-the-api.md) - Direct remote MCP access through the Messages API removed a client layer and moved agent integration from clever hacks toward engineering.
* [The MCP spec grows up](the-mcp-spec-grows-up.md) - OAuth 2.1 authorization, streamable HTTP, batching and tool annotations: the March 2025 update that made enterprise MCP plausible.
* [A2A and MCP: complementary, not competing](a2a-and-mcp-complementary-not-competing.md) - MCP connects agents to tools; Agent2Agent connects agents to each other. Together they turn single agents into systems, and raise the governance stakes.
* [Architecture-as-Code Control Plane](architecture-as-code-control-plane.md) - An executable, policy-aware governance engine that checks designs automatically before they reach production, so architecture keeps pace with AI-speed delivery.
* [Architecture-as-Code Reference Platform (open prototype)](architecture-as-code-reference-platform-open-prototype.md) - aac.muthub.org: a public, working prototype of an architecture control plane, with catalogs, OPA policies, waivers, an executive scorecard, a CLI and an MCP server that brings the rules into coding agents. It is modeled in its own notation and passes its own rules.
* [Enterprise Generative AI Architecture](enterprise-generative-ai-architecture.md) - An enterprise-grade Generative AI reference architecture: a governed path from experiment to production, adopted as the reference model across business lines.
* [Enterprise Identity & Access Management](enterprise-identity-access-management.md) - Built USAA's first Oracle Identity Federation servers and the access-management foundation for single sign-on, multi-factor authentication and partner integrations.
