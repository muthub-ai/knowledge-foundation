# Notes

* [The cost of unmanaged context](the-cost-of-unmanaged-context.md) - Enterprises budget for compute, models and licenses, but almost none budget for the context those models depend on. Unmanaged context is the largest cost nobody tracks, and every new AI agent adds to it.
* [Context fragmentation: why your agents keep starting from zero](context-fragmentation-why-your-agents-keep-starting-from.md) - The knowledge an agent needs is scattered across code, tickets, chat, wikis, incident tools and people's heads. Each fragment is accurate and useless alone. Fragmentation, more than model quality, is what makes enterprise agents brittle.
* [Not another data lake: context needs curation, not collection](not-another-data-lake-context-needs-curation-not-collection.md) - The tempting answer to fragmented context is to pour everything into one place. We tried that with data, and many lakes became swamps. A context layer has to be a curated overlay: retrieval-first, owned, and pointing back to the systems that hold the truth.
* [Passive capture: knowledge that writes itself, with humans who approve it](passive-capture-knowledge-that-writes-itself-with-humans-who.md) - Documentation fails because it is a second job. The knowledge we need is already produced as a by-product of work: commits, tickets, incidents, reviews and decisions. Capture it passively, distill it, and keep a human approval gate before anything becomes trusted.
* [Self-describing knowledge: why the Open Knowledge Format matters, and what enterprises must add](self-describing-knowledge-why-the-open-knowledge-format.md) - In June, Google Cloud published the Open Knowledge Format, and July's v0.2 added provenance, verification and freshness. It is the right foundation. Regulated enterprises still need to add ownership, classification and a policy for how much trust an agent needs before it acts.
* [Living documentation and the human trust gap](living-documentation-and-the-human-trust-gap.md) - Docs that regenerate on every commit describe what code does. The harder, more valuable problem is capturing why it exists.
